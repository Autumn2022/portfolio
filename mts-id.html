Клиентские пути

Способ аутентификации в сервис зависит от выбранного пользователем способа входа, входит он по номеру МТС или нет, от подключённых самим сервисом дополнительно возможных способов входа

  • 1.
    Вход по коду из СМС

    Способ входа по умолчанию

  • 2.
    Вход по паролю

    Используется, если пользователь установил в профиле способ входа по паролю

  • 3.
    Вход по паролю и коду из СМС

    Используется, если пользователь установил в профиле способ входа по 2fa

  • 4.
    Вход по Call Password ID

    Call Password ID — способ аутентификации, где пользователь звонит на бесплатный номер и после сброса звонка происходит вход в сервис

  • 5.
    Вход по отпечатку пальца или лицу (passkey)

    Если пользователь добавил ключ доступа

Все клиентские пути имеют формат оформления макетов через CJM от точки входа до финальных экранов. С описанием возможных проверок по ходу сценария, экранов ошибок и других ответвлений и состояний. Также все клиентские пути имеют ресайзы для Web Desktop
